# THE NOCTURNE - Cafe & Botanical Bar Landing Page 🍸☕

เว็บไซต์หน้าเดียว (Single Page Landing Page) สำหรับประชาสัมพันธ์ร้านคาเฟ่ & บาร์ ในสไตล์ **Dark Aesthetic โทนดำตัดขาว ผสมผสานไม้สักธรรมชาติ และบรรยากาศแมกไม้ร่มรื่น**

---

## 🌟 จุดเด่นและฟังก์ชันในหน้าเว็บ (Key Features)

1. **ดีไซน์ระดับพรีเมียม (Moody & Botanical Vibe)**
   - โทนสี: ดำด้าน (`Matte Black`) ตัดกับขาวคลีน อบอุ่นด้วยลายไม้สักแท้ (`Timber & Wood`) และสีเขียวจากพฤกษชาติ (`Botanical`)
   - ตัวอักษรหรูหรา: ผสมผสานฟอนต์สไตล์บาร์ระดับโลก **Cormorant Garamond** และฟอนต์ภาษาไทยโมเดิร์น **Prompt** จาก Google Fonts
   - แสงเงา Ambient Warm Light และประกายแสงสีอำพัน (Amber Glow)

2. **ระบบสลับบรรยากาศกลางวัน/กลางคืน (Day Cafe & Night Bar Toggle)**
   - สามารถกดปุ่มที่แถบเมนูด้านบนเพื่อเปลี่ยนมุมมองสถานะระหว่าง "Day Cafe (กาแฟ Specialty)" และ "Night Bar (คราฟต์ค็อกเทล & วิสกี้)"

3. **เมนูคราฟต์พร้อมระบบกรองหมวดหมู่ (Interactive Menu Filter)**
   - แบ่งเป็นหมวด: ทั้งหมด, ☕ Specialty Coffee, 🍸 Craft Cocktails, 🌿 Botanical Mocktails, 🥐 Bakery & Tapas
   - มีการระบุ Tasting Notes ส่วนผสม ราคา และภาพประกอบสวยงาม

4. **แกลเลอรีภาพบรรยากาศร้าน (Atmosphere Gallery & Lightbox Preview)**
   - แสดงมุมต่างๆ: เคาน์เตอร์บาร์ไม้สักทอง, โซนสวน Glasshouse, มุมชงกาแฟ Slow Bar, และโซฟาหนังส่วนตัว
   - สามารถคลิกที่รูปเพื่อเปิดดูภาพขยายขนาดใหญ่ (Lightbox Modal) ได้ทันที

5. **ระบบจองโต๊ะ / สำรองที่นั่งล่วงหน้า (Interactive Table Reservation)**
   - เลือกระบุ: วันที่, กะเวลา (Day / Night), จำนวนท่าน, และโซนที่นั่งที่ต้องการ
   - เมื่อกดส่ง จะมีป๊อปอัปสรุปข้อมูล พร้อมปุ่มคลิกส่งข้อมูลยืนยันเข้า **LINE Official** อัตโนมัติ

6. **แผนที่ Google Maps & ข้อมูลเวลาเปิด-ปิด**
   - แผนที่ฝังแบบ Interactive ในโทนสี Dark Mode สบายตา
   - ข้อมูลเวลาเปิด-ปิดแยกกะ Day & Night ชัดเจน
   - ปุ่มลอยด่วนมุมขวาล่างสำหรับโทรออก และเปิด LINE OA ทันที

## 🚀 วิธีเปิดใช้งาน

1. **เปิดดูในคอมพิวเตอร์ทันที:**
   - เพียงดับเบิลคลิกที่ไฟล์ `index.html` เพื่อเปิดผ่าน Google Chrome, Edge, Safari หรือ Browser ใดๆ ได้ทันที โดยไม่ต้องติดตั้งโปรแกรมเซิร์ฟเวอร์เสริม

2. **การปรับแต่งข้อมูลเป็นของร้านคุณ:**
   - **เปลี่ยนชื่อร้าน / สโลแกน:** ค้นหาคำว่า `NOCTURNE` ใน `index.html` แล้วเปลี่ยนเป็นชื่อร้านของคุณ
   - **เปลี่ยนเบอร์โทร / LINE:** ค้นหาเบอร์ `098-765-4321` และลิงก์ `https://line.me` ใน `index.html`
   - **เปลี่ยนเมนูและราคา:** แก้ไขข้อมูลในแท็ก `<div id="menu-items-grid">` ใน `index.html`
   - **เปลี่ยนรูปภาพ:** สามารถนำ URL ภาพจาก Facebook / Google Drive / ลิงก์ตรง หรือใส่รูปในโฟลเดอร์แล้วใส่ path ได้ทันที
